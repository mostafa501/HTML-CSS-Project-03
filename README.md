# HTML-CSS-PROJECT-03

A responsive multi-section website template built using **HTML5** and **CSS3** as part of my web development learning.

## 📌 Project Overview

This project is a front-end website created to practice and apply advanced **HTML and CSS** concepts, including complex layouts, animations, mega menus, hover effects, counters, and responsive design.

## 🛠 Technologies Used

* **HTML5**
* **CSS3**
* **Font Awesome**
* **Google Fonts (Cairo)**

## 📁 Project Structure

```text
HTML-CSS-PROJECT-03/
│
├── css/
│   ├── all.min.css
│   ├── normalize.css
│   └── elzero.css
│
├── imgs/
│   └── (all project images)
│
├── webfonts/
│   └── (Font Awesome webfonts)
│
└── index.html
```

## ✨ Project Features

* Responsive one-page website layout
* Header with navigation bar and Mega Menu
* Landing, Articles, Gallery, and Features sections
* Testimonials, Team, Services, and Skills sections
* Events, Pricing, Videos, and Stats sections
* Discount section with form
* Footer with social icons and links
* CSS variables, Flexbox, and CSS Grid
* Custom keyframe animations and hover effects
* Fully responsive using media queries

## 🎯 Learning Objectives

* HTML5 semantic structure
* CSS variables and pseudo-elements
* Flexbox and CSS Grid layouts
* Responsive design with media queries
* CSS animations, transitions, and counters
* Mega menu and hover interactions
* Organizing multi-file website assets
